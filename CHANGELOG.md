# Changelog

## 0.1.2 - 2026-11-14

- Rest the seated torso/butt on the taskbar edge.
- Rest lying and sleeping poses at the chest/elbows, with front paws hanging over.
- Keep hanging paws clickable and use consistent contact throughout expressions.
- Preserve approved artwork, physical scale, horizontal placement and animation timing.

## 0.1.1 - 2026-11-14

- Add a smaller Small size and rename the existing tiers Normal, Large and Extra Large.
- Default fresh settings to Small while preserving existing saved physical sizes.

## 0.1.0 - 2026-11-14

- Add approved sit, lie and head-down sleep poses and transitions in both directions.
- Add blinks, head tilts and tongue peek/retract actions in both awake poses.
- Add transparent, nonactivating desktop rendering, dragging, whole-body menus,
  outside-click dismissal, monitor controls and opt-in Windows startup.
- Add separate production/developer builds and a per-user installer/uninstaller.

The first GitHub release is 0.1.2. Earlier versions were local development builds.
